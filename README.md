# Ale — Sistema de anuncios UGC con IA

Repositorio base del proyecto. **Fase 1 (completada):** estudio y documentación completa del sistema
**AvatarHype™ — "Todos los formatos IA (menos animado)"**, que es la pieza de partida de un sistema
más grande que construiremos a continuación.

## Qué hay aquí

- **[`docs/SISTEMA-AVATARHYPE.md`](docs/SISTEMA-AVATARHYPE.md)** — Documento maestro: el sistema completo
  aprendido, el stack de herramientas, el flujo de trabajo, los 4 formatos y la hoja de ruta hacia la
  automatización. **Empieza por aquí.**
- **[`docs/INDICE-CURSO.md`](docs/INDICE-CURSO.md)** — Índice de las lecciones del curso con duración.
- `docs/transcripciones/` — Transcripción íntegra (subtítulos en español) de los 4 vídeos.
- `docs/notas-lecciones/` — Notas escritas de cada lección con sus enlaces.
- `docs/recursos-prompts/` — Bibliotecas de prompts reales extraídas (plantilla Veo, referencia visual,
  image-ads, trends, biblioteca Sora).

## Resumen en una línea

Producir anuncios de e-commerce con avatares de IA hiperrealistas (UGC, podcast, voz en off, dualcast,
imagen) por la ruta más barata del mercado (~0,07–0,16 €/clip) usando marketplaces de APIs (Kie, APImart),
modelos punteros (Veo 3.1, Omni Flash, GPT Image 2, Nano Banana Pro), agentes GPT para guiones/prompts y
CapCut para el ensamblado.
