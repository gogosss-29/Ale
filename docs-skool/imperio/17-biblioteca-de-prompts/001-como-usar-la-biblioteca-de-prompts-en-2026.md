# Cómo usar la Biblioteca de Prompts en 2026

---

Bienvenidos y bienvenidas a la **Biblioteca de Prompts** de Imperio Digital. Esta guía les ayudará a entender cómo usar la biblioteca **en 2026** — porque sí, las cosas cambiaron mucho desde que la armamos.

**Lo primero que tienes que saber:** un prompt ya no es una frase mágica que copias y pegas. Es una pieza de un sistema. Esta biblioteca es tu materia prima, pero la magia real pasa cuando la instalas dentro de un Project, le conectas tus datos, o la convertís en un agente.

## 1. Elige tu LLM

La biblioteca funciona con cualquiera, pero estos son los que recomiendo:

- **Claude (Opus o Sonnet)** → mi default. Mejor para copywriting, razonamiento, código, agentes, y todo lo que tenga MCPs conectados.
- **ChatGPT (GPT-5 o o3)** → cuando necesites browsing en vivo, imágenes con DALL-E, o voz.
- **Gemini 2.5** → si trabajas dentro de Google Workspace (Docs, Sheets, Gmail).

Si no sabes cuál usar, ve con Claude.

## 2. Cómo acceder a la biblioteca

**Paso 1:** Entra a Skool y ve a *Classroom*.

**Paso 2:** Selecciona *Biblioteca de Prompts*. Vas a ver las categorías (Copywriting, Meta Ads, Email, SEO, etc.).

**Paso 3:** Elige la categoría → la sub-categoría → y se te abre el prompt.

**Paso 4:** Copia el prompt. Ahora viene la parte que cambió: no lo pegues directo. Pasa a la sección 4.

## 3. Cómo leer un prompt

Cada prompt tiene tres partes:

- **Variables en corchetes** `[así]` → reemplázalas con tu información. Ejemplo: `[producto/servicio]` → `curso de inglés online`.
- **Estructura** marcada con `##` o etiquetas → es el esqueleto del prompt, no lo borres.
- **Notas al final** → indican qué modelo recomendamos y qué ajustes hacer.

## 4. Instala el prompt en vez de copiarlo cada vez

Esta es la diferencia entre usar la biblioteca como amateur y como pro.

**En Claude:**

1. Ve a *Projects* → *New Project*.
2. En *Custom Instructions* (o *System Prompt*), pega el prompt de la biblioteca.
3. Si el prompt usa datos tuyos (tu marca, tu cliente, tu producto), sube los archivos al Project.
4. Listo. Cada conversación nueva dentro de ese Project ya conoce el prompt.

**En ChatGPT:**

1. Crea un *GPT* o un *Project*.
2. Mismo flujo: prompt como instrucción de sistema + archivos de contexto.

**Bonus:** si manejas Claude Code o Cowork, convierte tus prompts más usados en *Skills* y se activan automáticamente cuando los necesitas.

## 5. Aprovecha Artifacts y Canvas

Para prompts que generan código, copy largo, landings, emails o documentos: pídele al modelo que te lo entregue como **Artifact** (Claude) o **Canvas** (ChatGPT). Así puedes iterar visualmente sin perder el hilo.

Ejemplo: "Genera la landing page como un Artifact de HTML, luego itero contigo".

## 6. Cuándo conectar un MCP en vez de pegar el prompt

Si el prompt necesita datos en vivo — Gmail, Slack, Notion, Drive, Meta Ads, Google Ads, analytics — no pierdas tiempo pegando data a mano. Conecta el MCP correspondiente y deja que el agente trabaje con tus datos reales.

Ejemplos:

- Prompt de *Reporte Semanal de Ads* → conecta Meta Ads + Google Ads MCP.
- Prompt de *Resumen de Reuniones* → conecta Granola o Gong MCP.
- Prompt de *Newsletter Semanal* → conecta Notion + Gmail MCP.

## 7. ¿Dudas?
