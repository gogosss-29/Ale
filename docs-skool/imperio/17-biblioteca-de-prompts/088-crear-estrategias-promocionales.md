# 🔥 Crear Estrategias Promocionales

> Ruta: Biblioteca de Prompts › 🔥 Crear Estrategias Promocionales

---

**Crear Estrategias Promocionales:** Lanza campañas que tus afiliados ejecuten plug-and-play. Menos improvisación, más revenue sistemático.

**Recomendación de modelo:** **Claude (Opus o Sonnet)**. Crea un **Project en Claude** con producto + audiencia + oferta—cada nueva campaña se arma en minutos.

**1. Calendario anual de campañas**

```jsx
Mi producto: [qué vendo + precio]
Mi audiencia: [perfil]

Diseña calendario anual:

1. RECURRENTES: lanzamiento trimestral, mid-month flash, end-of-month push
2. ESTACIONALES: BFCM, Year-end, Mid-year reset, industry holidays
3. EVENTOS: lanzamientos, aniversarios, hitos
4. OPORTUNIDAD: trending del nicho, news-jacking
5. NURTURE: re-engagement, win-back, VIP-only

Formato: tabla con fecha, tipo, objetivo, oferta, mecánica, KPI.
```

**2. Anatomía de campaña ganadora**

```jsx
CAMPAÑA: [nombre] | TIPO + DURACIÓN + OBJETIVO + TARGET

1. HOOK / BIG IDEA: una frase que define todo
2. OFERTA: qué incluye, precio, bonos, garantía, stack value
3. URGENCIA LEGÍTIMA: timing real, fecha + hora cierre
4. PRUEBA: testimonials, cifras, casos
5. MECÁNICA FUNNEL: tráfico frío/warm/hot → ruta específica
6. COMISIÓN afiliados: % extra + bonificaciones por hitos

Entrégame brief listo para afiliados.
```

**3. Toolkit plug-and-play**

```jsx
1. EMAILS SWIPES (5): announcement, launch day, mid-campaign, 24h warning, last call
2. SOCIAL POSTS por plataforma: X, LinkedIn, IG, TikTok, FB
3. BANNERS: 5 sizes, 3 variantes cada, editable
4. VIDEO TEMPLATES: 60-90 seg pitch, 30 seg reel, 5-7 min review
5. BLOG POST TEMPLATE: outline 1500 palabras + hooks + CTAs
6. LANDING PAGE CO-BRANDED editable
7. AFFILIATE LINKS con UTMs preconfigurados

Objetivo: afiliado promueve en 10 min de recibir toolkit.
```

**4. Promoción del programa**

```jsx
1. PRE-LAUNCH: email a todos, Slack teaser, DM top 10, webinar opcional
2. LAUNCH DAY: email main + toolkit + live Q&A 30 min + recording
3. DURING: daily leaderboard, featured moments, asset drops mid-campaign, mini-contests
4. CONTESTS: top 3 prize, best improvement, best creative, newcomer
5. POST-CAMPAIGN: results email, reconocimiento público, lessons compartidas, tease próxima
```

**5. Tracking + atribución**

```jsx
1. SETUP: links con tracking, pixel/CAPI, eventos, hold period
2. ATRIBUCIÓN: last-click / first-touch / multi-touch + cookie window
3. DASHBOARD LIVE: revenue, CR, top 10 real-time, geos
4. REPORTE: vs target, vs anterior, vs benchmark, ROI vs paid ads
5. INDIVIDUAL REPORT: personalizado con tip específico
6. LESSONS LEARNED: qué sí/no, sorpresas, action items

Objetivo: cada campaña mejor que la anterior.
```

*Tip pro:* **Scheduled task en Claude** cada lunes durante campaña activa: "hot performers, dormants a empujar, hito vs target". Gestión proactiva en piloto automático.
