# Orientación para Gestión de Crisis

> Ruta: Biblioteca de Prompts › Orientación para Gestión de Crisis

---

**Manejo de Crisis:** Brinda respuestas adaptadas a situaciones de crisis. Ofrece asesoramiento práctico y sugerencias. Reduce estrés y ansiedad, facilita toma de decisiones informadas.

```jsx
"En caso de un [crisis específica], ¿cuáles son los pasos más efectivos que [grupo específico] puede tomar para asegurar [resultado específico]?"

```

```jsx
"¿Qué [tipo específico de entrenamiento/educación/plan] debería tener [organización específica] para prepararse para un [tipo específico de crisis]** que podría afectar a [grupo específico]?"

```

```jsx
"Considerando las necesidades únicas de [grupo específico de personas], ¿cuáles son las mejores prácticas para [acción específica] durante un [tipo específico de crisis]?"

```

```jsx
"¿Puedes proporcionar orientación sobre cómo [organización específica] puede gestionar eficazmente un [tipo específico de crisis] mientras también aborda [preocupación/impacto específico]?"

```

```jsx
"¿Cuáles son los factores más importantes a considerar cuando [acción específica] en las secuelas de un [tipo específico de crisis] que ha impactado a [grupo específico]?"

```
