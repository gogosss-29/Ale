# Generación de Imágenes que Captan la Atención

> Ruta: Biblioteca de Prompts › Generación de Imágenes que Captan la Atención

---

**ChatGPT en Generación de Ideas de Imágenes:** Deja que ChatGPT despierte tu creatividad. Genera ideas de imágenes sorprendentes para redes sociales o carteles. ChatGPT se encarga de todo, solo relájate y deja que las palabras fluyan.

```jsx
"Visualiza un concepto que presente [producto/servicio] en un estilo [moderno/minimalista/vintage, etc.]. ¿Cómo puedes usar la tipografía, el color y otros elementos de diseño para lograr este aspecto y sensación?"

```

```jsx
"Genera un concepto que muestre [producto/servicio] como la elección definitiva para [audiencia objetivo]. ¿Qué elementos puedes agregar a la imagen para que sea atractiva y relevante para esta audiencia?"

```

```jsx
"Concibe una imagen que demuestre claramente las ventajas de [producto/servicio] de una manera atractiva y convincente. ¿Cómo puedes usar el color, la forma y otros elementos de diseño para que la información sea más atractiva y efectiva?"

```

```jsx
"Piensa en una forma de presentar las características clave de **[producto/servicio]** de una manera divertida y memorable. ¿Qué elementos puedes agregar al concepto para que sea más entretenido y atractivo?"

```

```jsx
"Idear un concepto que combine [producto/servicio] con [evento/feriado/estación] de una manera festiva y cautivadora. ¿Cómo puedes usar imágenes y elementos temáticos del feriado para crear una imagen que destaque?"

```
