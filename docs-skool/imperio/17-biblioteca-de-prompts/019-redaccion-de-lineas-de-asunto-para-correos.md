# Redacción de líneas de asunto para correos

> Ruta: Biblioteca de Prompts › Redacción de líneas de asunto para correos

---

**ChatGPT en Líneas de Asunto de Correos Electrónicos:** Genera líneas de asunto personalizadas para tus campañas. Proporciona detalles del producto, audiencia objetivo y acción deseada, y obtén líneas de asunto efectivas para tus correos electrónicos promocionales.

### Prompts

```jsx
"Voy a enviar un correo electrónico para anunciar una nueva [característica/oferta] y necesito una línea de asunto llamativa que capte la atención de mi audiencia. ¿Puedes ayudarme a idear algunas opciones?"

```

```jsx
"Estoy redactando un correo electrónico para promocionar nuestro [producto/servicio], y necesito una línea de asunto convincente que anime a los destinatarios a abrir el correo. ¿Puedes ayudarme a generar varias opciones?"

```

```jsx
"Estoy buscando una línea de asunto para un recordatorio por correo electrónico sobre [evento/plazo]. El correo se enviará a [audiencia objetivo] y el objetivo es [acción deseada por el destinatario]. ¿Puedes generar una línea de asunto que sea [tono/estilo específico] e incluya [palabras clave/frases]?"

```
