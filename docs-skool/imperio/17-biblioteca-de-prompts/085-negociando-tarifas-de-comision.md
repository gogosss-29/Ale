# Negociando Tarifas de Comisión

> Ruta: Biblioteca de Prompts › Negociando Tarifas de Comisión

---

**Negociación de Tarifas de Comisión:** No regales la casa, pero tampoco pierdas top afiliados por 2% de margen. Negociación basada en data + leverage + win-win.

**Recomendación de modelo:** **Claude (Opus o Sonnet)**. Conecta **MCP de tu CRM / plataforma** para que Claude haga el cálculo financiero exacto antes de negociar.

**1. Pre-negociación: cálculo financiero**

```jsx
Mi producto: [precio + COGS + márgenes]
Comisión actual: [%]
LTV promedio: [$]
CAC vía otros canales: [$]

Dame los números:

1. MAX COMISIÓN SOSTENIBLE: punto donde aun me conviene vs invertir en Ads/organic
2. BENCHMARK industria: promedio nicho + top tier competencia
3. ROI POR TIER: % donde aun deja margen sano
4. ESCENARIOS: si subo 5% / 10% / rev-share extendido
5. ALTERNATIVAS no-monetarias: bonuses, co-branding, exclusividad

Objetivo: negociar con números, no con miedo.
```

**2. Negociación con top performers existentes**

```jsx
Top performer pide subir comisión. Antes de decir sí o no:

1. CALIFICA: revenue, tendencia, calidad, esfuerzo, reputación
2. ENTIENDE EL MOTIVO: ¿oferta competencia? ¿más revenue? ¿reconocimiento?
3. OPCIONES de respuesta:
   - A: subir comisión base
   - B: bonus por hitos (premia performance sostenida)
   - C: rev-share extendido
   - D: non-monetary (co-branding, acceso)
   - E: combinación
4. SCRIPT: reconoce valor con data + pregunta abierta + presenta 2-3 opciones + pide compromiso
5. CLOSER: trial 90 días. Si rinde, permanente.

Objetivo: ambos sienten que ganaron.
```

**3. Negociación con prospects nuevos**

```jsx
Vas a fichar un creator importante.

1. ESTABLECER VALOR antes del precio:
   - Casos de éxito de afiliados similares
   - Soporte del programa
   - Por qué su audiencia sí compraría

2. ANCHOR con datos:
   - "Mi top gana $X/mes con [%]"
   - EPC promedio + benchmark
   - Calculadora interactiva

3. RANGES:
   - Standard
   - Premium (alto volumen comprometido): +20-30%
   - Custom top-tier: case-by-case

4. EXCLUSIVIDAD vs no:
   - Exclusive: permite ofrecer más
   - Non-exclusive: comisión estándar

5. SI PIDE MÁS: pregunta qué compromiso ofrece (volumen, contenido, exclusividad)

Reglas: no desesperación, no decisión el primer día, BATNA claro, walk-away point.
```

**4. Counter-offers de competencia**

```jsx
Top afiliado dice "competencia ofrece 30% vs tus 20%".

1. NO PANIC. Verifica: ¿cierto o leverage?
2. EVALÚA matching:
   - % de revenue que representa
   - Costo de perderlo vs matching
   - Risk de cascade (otros piden igual)
3. RESPUESTA:
   - Vale: igualar o cerca + commitment del afiliado
   - No vale: ser honesto, no matching
   - Mentiroso: ofrecer creative, no matching directo
4. NUNCA matching ciego:
   - Si matcheas, pide algo a cambio
   - Ej: "matcheamos 30% con exclusividad 6 meses + volumen mínimo"
5. POST-MATCHING: invertir en retention real, no solo $
```

**5. Estructura tier pública**

```jsx
Para evitar negociaciones caso-por-caso:

TIER 1 BASE: arrancan todos
- Comisión: [X%]
- Pago: net 30
- Cookie window: 30-60 días

TIER 2 PERFORMER: 3+ ventas/mes consistente
- Comisión: [X+5%]
- Trigger automático 3 meses seguidos
- Soporte priority, webinars exclusivos

TIER 3 PRO: $5k+/mes
- Comisión: [X+10%]
- Bonificaciones por hito
- Co-branded materials
- 1:1 manager mensual

TIER 4 PARTNER: $20k+/mes O top 5%
- Comisión negociable: hasta [X+15%]
- Rev-share extendido
- Acceso founder
- Co-creation productos
- Annual summit

REGLAS movimiento:
- Promoción automática con criterios 3 meses
- Democión con warning si cae 2 meses
- Re-evaluación Q1

COMUNICACIÓN:
- T&C públicos
- Email anual con estado
- Dashboard de progreso

Reglas: mísmas para todos. Excepciones documentadas.
```

*Tip pro:* Conecta **MCP de plataforma**. Scheduled task mensual evalué promociones/demociones automáticamente + manda emails personalizados. Cero esfuerzo, máxima transparencia.
