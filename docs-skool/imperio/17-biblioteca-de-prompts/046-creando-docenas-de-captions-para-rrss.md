# Creando Docenas de Captions Para RRSS

> Ruta: Biblioteca de Prompts › Creando Docenas de Captions Para RRSS

---

**ChatGPT puede ayudarte a crear captions o leyendas geniales** para tus fotos y publicaciones en redes sociales. Solo proporciona un tema o indicación específica, y ChatGPT generará una leyenda que atrape la atención de tu audiencia. ¡Dale a tus fotos el toque perfecto con las leyendas de ChatGPT!

### Prompts

```jsx
"¿Puedes sugerir un caption divertido para un momento de [insertar evento/momento]?"

```

```jsx
"Quiero un caption que exprese mi [emoción] por [evento/experiencia]. ¿Puedes ayudar?"

```

```jsx
"¿Puedes crear un caption que incluya las palabras [insertar palabra clave/frase]?"

```

```jsx
"Necesito un caption que resuma mi [insertar experiencia/aventura]. ¿Puedes crear una?"

```

```jsx
"Necesito un caption que transmita [insertar emoción/sentimiento]. ¿Puedes ayudar?"

```
