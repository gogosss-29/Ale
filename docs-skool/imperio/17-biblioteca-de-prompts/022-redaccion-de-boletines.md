# Redacción de Boletines

> Ruta: Biblioteca de Prompts › Redacción de Boletines

---

**Uso de ChatGPT en Redacción de Boletines Electrónicos:**

1. Prepara un inicio para ChatGPT que incluya información sobre el tema del boletín, la audiencia prevista y el tono deseado.
2. Usa el inicio para generar texto con ChatGPT. Puedes hacer esto ingresando el inicio en el modelo y recuperando el texto generado.
3. Revisa el texto generado y edítalo según sea necesario para que sea más personalizado y preciso. También puedes agregar cualquier información específica que desees incluir en el boletín.
4. Formatea el boletín e incluye imágenes u otros medios que desees agregar.
5. Envía el boletín a tu audiencia prevista.

Es importante tener en cuenta que el texto generado puede no ser perfecto y requerir cierta edición. Además, puedes ajustar el modelo de ChatGPT con tu propio conjunto de datos para mejorar el texto generado y hacerlo más relevante para tu audiencia e industria específicas.

### 

```jsx
"Escribe un boletín para [audiencia] sobre [tema]. El tono debe ser [formal/informal/etc.] e incluir información sobre [información específica o puntos clave a incluir]."

```

También puedes incluir una sección opcional para afinar el texto generado de manera más específica para tu audiencia, por ejemplo: "y para nuestros clientes objetivo [clientes objetivo], el boletín debe hacer hincapié en [hacer hincapié en]"

También puedes incluir otra sección opcional para agregar una llamada a la acción específica que deseas incluir en el boletín, por ejemplo: "y el boletín debe finalizar con una llamada a la acción para [llamada a la acción]”

```jsx
"Escribe un boletín electrónico sobre el próximo lanzamiento de nuestro nuevo producto [nombre del producto]."

```

```jsx
"¿Puedes ayudarme a escribir un boletín electrónico para mi negocio, dirigido a [audiencia objetivo] y promocionando nuestro nuevo servicio [nombre del servicio]?"

```

```jsx
"Genera un boletín electrónico para el próximo evento de mi empresa [nombre del evento]."

```

```jsx
"Escribe un boletín electrónico que promocione nuestro nuevo producto [nombre del producto] e incluya una llamada a la acción para visitar nuestro sitio web para obtener más información."

```
