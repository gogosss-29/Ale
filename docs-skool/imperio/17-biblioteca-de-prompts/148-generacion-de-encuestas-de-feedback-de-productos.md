# Generación de Encuestas de Feedback de Productos

> Ruta: Biblioteca de Prompts › Generación de Encuestas de Feedback de Productos

---

**ChatGPT en Encuestas de Feedback/Retroalimentación de Productos**: Genera encuestas efectivas con lenguaje natural. Captura opiniones y pensamientos de los usuarios sobre productos o servicios. Sugerimos preguntas de seguimiento para obtener información detallada. Impulsa la retroalimentación con ChatGPT.

```jsx
"¿Puedes ayudarme a crear una encuesta de retroalimentación de productos para [producto/servicio] que se dirija a [audiencia/específica/grupo] y se centre en [aspecto/específico del producto/servicio] para comprender mejor [meta/específica o objetivo/específico]?"

```

```jsx
"¿Cuáles son algunas áreas clave que deberíamos priorizar en nuestra encuesta de retroalimentación de productos para [producto/servicio] para obtener información sobre [meta/específica o objetivo/específico]? ¿Puedes proporcionar algunas preguntas de muestra que aborden estas áreas, como [preguntas de muestra específicas]?"

```

```jsx
"Queremos crear una encuesta de retroalimentación de productos que recopile comentarios sobre [característica/específica o aspecto/específico] y también capture [métrica/específica/punto de datos de retroalimentación/específico]. ¿Puedes sugerir algunas preguntas que nos ayuden a lograr estos objetivos, como [preguntas específicas]?"

```

```jsx
"¿Cómo podemos estructurar nuestra encuesta de retroalimentación de productos para alentar a los encuestados a proporcionar comentarios detallados y accionables, al mismo tiempo que reconocemos posibles áreas de mejora o deficiencias en [producto/servicio]? Por ejemplo, podríamos preguntar [preguntas específicas que aborden deficiencias y alienten la retroalimentación]?"

```

```jsx
"¿Puedes ayudarnos a analizar las respuestas que recibimos de nuestra encuesta de retroalimentación de productos e identificar áreas de mejora, como [métricas específicas/puntos de datos a tener en cuenta] y [herramientas/técnicas específicas para el análisis]?"

```
