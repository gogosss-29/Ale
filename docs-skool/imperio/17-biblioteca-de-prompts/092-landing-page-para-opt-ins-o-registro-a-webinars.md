# Landing Page (Para Opt-ins o Registro a Webinars)

> Ruta: Biblioteca de Prompts › Landing Page (Para Opt-ins o Registro a Webinars)

---

**Escribir una Página de Aterrizaje para Opt-ins o Registro a Seminarios Web con ChatGPT**: Convierte visitantes en suscriptores o asistentes a tus seminarios web con una página de aterrizaje efectiva. ChatGPT te brinda la ayuda necesaria para redactar una página persuasiva que capte la atención de tu audiencia y la motive a tomar acción. Impulsa tu lista de correo o el registro a tus eventos con ChatGPT

```jsx
Escribe una página de aterrizaje que ofrezca un [imán de leads] a [audiencia]. Este [ebook/seminario web/serie de videos] gratuito les ayudará con:
- [Beneficio 1]
- [Beneficio 2]
- [Beneficio 3]
Menciona que es completamente gratuito y que puedo ayudarles porque [incluye credenciales].

```

```jsx
¿Puedes ayudarme a crear una página de aterrizaje para mi [producto/servicio] que convierta a los visitantes en clientes? Aquí tienes algunos detalles sobre mi [producto/servicio]: [inserta detalles como beneficios, puntos de venta únicos, público objetivo, etc.].

```
