# Desarrollo de Nuevas Ofertas

> Ruta: Biblioteca de Prompts › Desarrollo de Nuevas Ofertas

---

**Desarrollo de Nuevas Ofertas:** Lanza ofertas frescas periódicamente para mantener tu programa de afiliados energético. Bonos, bundles, ofertas limitadas que ELLOS pueden promover con autoridad.

**Recomendación de modelo:** **Claude (Opus o Sonnet)**. Conecta el **MCP de tu e-commerce/checkout** para que Claude vea qué ofertas convierten mejor con tu data histórica.

**1. Audit de ofertas actuales**

```jsx
Mi oferta principal actual: [precio + bonos + garantía]
Mis afiliados activos: [#]
Frecuencia de nuevas ofertas: [cada cuánto]

Audítame:

1. PERFORMANCE actual:
   - Conversion rate del afiliado promedio
   - EPC (Earnings Per Click)
   - AOV (Average Order Value)
   - Refund rate

2. FATIGA DE OFERTA:
   - ¿Afiliados llevan +90 días con la misma oferta?
   - CTR cayendo en sus posts/emails sobre mi producto?
   - Top afiliados promoviendo menos?

3. BENCHMARK competencia:
   - ¿Qué ofrecen ellos que yo no?
   - ¿Qué promociones especiales lanzan y cuándo?
   - Mi competitive advantage actual

4. OPORTUNIDADES de nueva oferta:
   - Bundles + cross-sell
   - Ofertas estacionales (BFCM, Q1, mid-year)
   - Ofertas verticales (por nicho de afiliado)
   - Ofertas por evento

Formato: 1 página + recomendación de próxima oferta.
```

**2. Generador de bundle/bonus stack**

```jsx
Mi producto base: [producto + precio]
Margen actual: [%]
Mi audiencia: [perfil]

Diseña 5 bundles que pueda lanzar:

PARA CADA BUNDLE:
1. NOMBRE atractivo (no "Bundle Premium")
2. QUÉ INCLUYE (producto base + 3-5 bonos)
3. VALOR PERCIBIDO total
4. PRECIO REAL del bundle
5. COSTO REAL para mí
6. MÁRGENES finales (sostiene comisión + ganancia)
7. EXCLUSIVIDAD (solo afiliados / time-limited / all-time)
8. ENTREGABLES (digital / físico / acceso / consulta)

TIPOS A EXPLORAR:
- "Starter" (producto + onboarding intensivo)
- "Pro" (producto + herramientas + comunidad)
- "Done For You" (producto + servicio implementación)
- "VIP" (producto + acceso founder)
- "Tools" (producto + integraciones / templates)

Reglas:
- Cada bono debe sentirse INDISPENSABLE
- Nunca más de 5 bonos
- Mínimo 1 bono instantáneo (gratification)

Dame top 2 con justificación.
```

**3. Ofertas con urgencia legítima**

```jsx
La urgencia falsa mata confianza. La urgencia real convierte sin quemar audiencia.

Diseña 5 ofertas con urgencia legítima:

1. STOCK LIMITADO REAL (inventario/slots)
2. PRICE INCREASE NEXT WEEK (realmente vas a subirlo)
3. EVENT-DRIVEN (BFCM, Cyber Monday, etc.)
4. ANIVERSARIO / MILESTONE de marca
5. EARLY BIRD de lanzamiento de producto nuevo

PARA CADA OFERTA:
- Duración recomendada (24h / 72h / 7d)
- Cuándo anunciar / abrir / cerrar
- 3 emails para que afiliados promuevan
- Cómo mostrar countdown sin ser cringe
- Si "cierra", ¿vuelve a abrir? Si vuelve, no es urgencia real

Reglas:
- NUNCA inventar urgencia
- NUNCA reabrir después de cerrar (quema credibilidad)
- Si extiendo deadline, justificarlo públicamente
```

**4. Ofertas verticales por tipo de afiliado**

```jsx
Un YouTuber nicho A y un blogger nicho B necesitan ofertas distintas.

Diseña 3 ofertas verticales:

VERTICAL 1: para CREATORS (YouTube/TikTok/IG)
- Bonus que su audiencia valoré específicamente
- Co-branded landing page
- Comisión boost para creators +X seguidores
- Soporte: clips de tu producto listos

VERTICAL 2: para LONG-FORM (bloggers/newsletter/SEO)
- Bonus orientado a audiencia más analítica
- Landing optimizada post-blog
- Compensation: rev-share extendido
- Soporte: data para artículos, backlinks

VERTICAL 3: para WARM AUDIENCE (community owners, masterminds)
- Bonus alto valor (alto trust, alto LTV)
- Acceso exclusivo a founder/team
- Comisión top-tier
- Soporte: workshops co-branded

Para cada vertical:
- Por qué encaja
- Cómo el afiliado la promueve
- Targeting específico
- KPIs distintos

Objetivo: cada tipo de afiliado siente que LA oferta fue diseñada para ellos.
```

**5. Playbook de lanzamiento de oferta**

```jsx
Una oferta mal lanzada rinde 30% de su potencial.

PRE-LANZAMIENTO (semana -2):
- Email a top 10 afiliados: heads-up + sneak peek
- Slack/Discord: teaser (no spoilers)
- Prep assets: swipe files + landing co-branded + videos

LANZAMIENTO DÍA 0:
- Email main a TODOS los afiliados
- Webinar 30 min Q&A
- Slack/Discord: kit completo de assets

WAVE 1 (días 1-3):
- Top afiliados promueven primero
- Daily leaderboard
- Spotlight de earliest converters

WAVE 2 (días 4-7):
- Email a afiliados sin tráfico
- Contest lámpago: top 3 ganan bonus

WAVE 3 (días 8-14):
- Si time-limited: countdown emails
- Re-engage afiliados dormidos
- Closing push

POST-LANZAMIENTO:
- Email cierre con resultados
- Plan de transición a siguiente oferta

Reglas: si afiliado X ya hizo venta, sacarlo de "reminder" list. CRM/segmentación crítica.
```

*Tip pro:* Crea un **scheduled task en Claude** que cada inicio de trimestre analice qué ofertas funcionaron, cuáles se quemaron, y proponga la próxima oferta basada en data de los últimos 90 días.
