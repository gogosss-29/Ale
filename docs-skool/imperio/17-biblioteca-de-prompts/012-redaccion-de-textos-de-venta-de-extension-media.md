# Redacción de Textos de Venta de Extensión Media

> Ruta: Biblioteca de Prompts › Redacción de Textos de Venta de Extensión Media

---

**ChatGPT: Asistente de Redacción**: ChatGPT es tu compañero de redacción perfecto, generando textos de venta persuasivos y eficaces. Actúa como un motivador personal para tus estrategias de venta, todo sin comisión alguna.

### Prompts

```jsx
"Escribe un discurso de venta para un [producto/servicio] que resalte sus características y beneficios únicos."

```

```jsx
"Escribe un correo electrónico persuasivo a un cliente potencial explicando por qué deberían elegir [nombre de la empresa] para sus necesidades de [producto/servicio]."

```

```jsx
"Escribe una entrada persuasiva de blog sobre los beneficios de usar [producto/servicio] para [industria específica/mercado objetivo]."

```

```jsx
"Redacta un anuncio de ventas para un [producto o servicio] que destaque sus características únicas y beneficios. Incluye detalles específicos sobre cómo puede resolver un problema o mejorar la vida del cliente".

```
