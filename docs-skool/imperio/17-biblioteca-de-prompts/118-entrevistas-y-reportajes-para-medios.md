# Entrevistas y Reportajes para Medios

> Ruta: Biblioteca de Prompts › Entrevistas y Reportajes para Medios

---

**Entrevistas y Reportajes:** Genera preguntas, información de fondo, puntos de discusión y titulares. Extensa base de datos de conocimientos. Crea contenido atractivo e informativo.

### 

```jsx
"Estoy trabajando en una pieza de medios sobre [tema], y necesito algunos puntos de datos específicos para apoyar mi artículo. ¿Podrías proporcionarme [número] de [datos específicos] y tal vez alguna [comparación o tendencia interesante] relacionada con [tema]?"

```

```jsx
"Al prepararme para una entrevista sobre [tema], quiero asegurarme de que mis preguntas estén adaptadas a la experiencia de mi entrevistado. ¿Podrías sugerirme algunas [preguntas específicas o temas] relacionadas con [rol o experiencia del entrevistado], y algunos [subtemas o preguntas de seguimiento] para explorar?"

```

```jsx
"Estoy escribiendo una pieza sobre [tema] y quiero incluir algunas citas relevantes de expertos en el campo. ¿Podrías sugerirme algunos [expertos específicos u organizaciones] que sean relevantes y algunas [posibles citas u opiniones] que puedan tener sobre [subtema relacionado]?"

```

```jsx
"Estoy trabajando en una pieza de medios sobre [industria/campo], y quiero asegurarme de que cubra el contexto histórico y su evolución a lo largo del tiempo. ¿Podrías proporcionarme algunos [hitos o eventos específicos] en la historia de [industria/campo], y tal vez alguna [comparación o tendencia interesante] relacionada con [tema]?"

```

```jsx
"Estoy tratando de encontrar algunos ángulos únicos para mi pieza de medios sobre [tema], ¿podrías sugerirme algunos [demográficos específicos, eventos o factores] que podrían estar relacionados con [tema] y algunos [posibles entrevistados o expertos] que puedan proporcionar información sobre ello?"

```
