# Redacción de un Brief para un Editor de Video

> Ruta: Biblioteca de Prompts › Redacción de un Brief para un Editor de Video

---

**ChatGPT en Briefs de Video:** ChatGPT crea briefs de video impresionantes para vencer el bloqueo del escritor. Tu propio J.K. Rowling de briefs de video. ¡Prepárate para la magia de la edición de video!

```jsx
"¿Puedes redactar un brief para un video de [estilo/tipo] que se utilizará para promocionar nuestro [producto/servicio/marca] a [audiencia objetivo]?"

```

```jsx
"¿Puedes redactar un brief para un video de [duración] que se utilizará para explicar la [misión/valores de nuestra empresa] a posibles clientes?"

```

```jsx
"¿Puedes crear un brief para un video [explicativo/de cómo hacer algo] que se utilizará para demostrar los pasos para utilizar nuestro [producto/servicio] de manera efectiva a **[clientes nuevos/existentes]"

```

```jsx
"Estoy planeando crear un video que eduque a mi audiencia sobre [tema]. ¿Puedes ayudarme a redactar un brief para el editor de video que incluya información sobre el tono, ritmo y resultado deseado del video?"

```

```jsx
"Necesito crear un video que muestre las características de [producto/servicio]. ¿Puedes ayudarme a redactar un brief para el editor de video que destaque los puntos de venta clave y diferencie nuestra oferta de la competencia?"

```
