# Generando Ideas de Contenido

> Ruta: Biblioteca de Prompts › Generando Ideas de Contenido

---

**ChatGPT en Generación de Ideas de Contenido:** Crea ideas únicas, creativas y atractivas para mantener a tu audiencia interesada. Utiliza su amplio conocimiento y comprensión del lenguaje para generar ideas de contenido de calidad. Mantente al tanto de las últimas tendencias y mejores ideas con la ayuda de ChatGPT.

```jsx
"Estoy buscando crear contenido sobre [tema]. ¿Puedes ayudarme a generar una lista de posibles ideas de artículos y títulos?"

```

```jsx
"Estoy tratando de ampliar mi portafolio de contenido escribiendo sobre [industria/nicho]. ¿Puedes ayudarme a crear una lista de temas que serían de interés para mi [audiencia objetivo]?"

```

```jsx
"Quiero crear una serie de publicaciones en mi blog que cubran lo básico de [tema]. ¿Puedes ayudarme a generar una lista de subtemas y títulos para estas publicaciones?"

```

```jsx
"Estoy buscando ampliar el contenido en mi sitio web, pero me cuesta encontrar nuevas ideas. ¿Puedes ayudarme a generar una lista de posibles temas para mi negocio de [industria/nicho]?"

```

```jsx
"Soy un creador de contenido y estoy buscando nuevas ideas para mi **[canal de YouTube/cuenta de Instagram]. ¿Puedes ayudarme a generar una lista de posibles **[temas de video/publicaciones] que serían populares entre mi audiencia **[tipo de audiencia]?"

```
