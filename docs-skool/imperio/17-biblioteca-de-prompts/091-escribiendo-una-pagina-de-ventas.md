# 🔥 Escribiendo una Página de Ventas

> Ruta: Biblioteca de Prompts › 🔥 Escribiendo una Página de Ventas

---

**Escribiendo una Página de Ventas:** La sales page convierte o muere tu funnel entero. Estructura probada + copy emocional + manejo de objeciones = conversión sostenida.

**Recomendación de modelo:** **Claude (Opus o Sonnet)**. Pega 2-3 sales pages que admires al inicio del chat para que Claude capture tu estilo objetivo.

**1. Pre-work: clarity de avatar + oferta**

```jsx
Mi producto: [qué vendo]
Mi avatar: [ultra-específico, no "emprendedores"]
Precio: [$X]

Clarifica:
1. AVATAR: demografías + situación + frase literal del problema + 3 objeciones + 3 deseos + 3 miedos
2. OFERTA STACK: producto core + bonos con valor percibido + garantía + soporte + stack value total vs precio
3. PRUEBA SOCIAL: testimonials (#), casos con cifras, logos, credenciales propias
4. DIFERENCIADOR: 1 frase + mecanismo único (método, framework)
5. URGENCIA LEGÍTIMA (cero falsa)

Claridad antes de palabras.
```

**2. Estructura completa de la sales page**

```jsx
SECCIÓN 1 HERO: pre-headline + headline (máx 15 palabras) + sub-headline + video/imagen + CTA suave

SECCIÓN 2 AGITATE: identifica situación + dolores específicos (3-5) + costo de no resolver

SECCIÓN 3 TRANSICIÓN: "¿qué pasaría si...?" + reconocimiento de intentos previos

SECCIÓN 4 SOLUCIÓN: producto + mecanismo único + 3-5 pasos cómo funciona + resultados típicos

SECCIÓN 5 PRUEBA SOCIAL: 3-5 testimonios específicos + 2-3 casos con cifras + logos/medios

SECCIÓN 6 OFERTA STACK: componentes detallados + bonos con valor + stack value total + precio anchor

SECCIÓN 7 GARANTÍA + reasoning de por qué puedes ofrecerla

SECCIÓN 8 FAQ: 6-8 que manejen objeciones típicas

SECCIÓN 9 CTA FINAL: recap del valor total + urgencia legítima + botón

SECCIÓN 10 P.S.: 1-2 que respondan objeciones finales

Dame copy completa, no solo outline.
```

**3. Headlines / hooks (8 variantes)**

```jsx
El headline hace o rompe la sales page.

1. TRANSFORMACIÓN: De X a Y en [tiempo]
2. PROMESA + MECANISMO: Cómo [resultado] usando [método único]
3. CONTRARIAN: Por qué [creencia popular] está mal y qué hacer
4. PREGUNTA: ¿Quieres [resultado] sin [dolor común]?
5. STAT: [Número impactante] [resultado], aquí está cómo
6. STORY: Cómo [persona] logró [resultado] después de [dolor]
7. CONOCIMIENTO OCULTO: El [tema] que [autoridades] no quieren que sepas
8. DIRECTO: [Resultado] garantizado en [tiempo]

Reglas: máx 15 palabras, específico, cero "finalmente" / "revolución". Marca [VERIFICAR] datos.

Para cada: score 1-10 de retención + estado emocional + audiencia ideal.
```

**4. Manejo de objeciones**

```jsx
8 objeciones típicas y cómo manejarlas:

1. NO TENGO TIEMPO → time-saving del producto, sistema simple, plan claro
2. NO TENGO DINERO → cost of not buying, payment plan, ROI específico
3. YA INTENTÉ → diferenciador, mecanismo único, casos similares al avatar
4. MI CASO ES DISTINTO → 3-4 mini-casos de perfiles A/B/C
5. ¿FUNCIONARÁ PARA MÍ? → garantía + caso específico
6. ¿POR QUÉ AHORA? → urgencia legítima + costo de esperar
7. ¿QUÉ PASA SI NO FUNCIONA? → garantía específica + proceso refund
8. ¿PUEDO BAJARME DESPUÉS? → política clara

Para cada: dónde en la page, copy exacta del FAQ, sección especial si lo requiere.

Anticipar antes de que las piensen.
```

**5. Test + iteración**

```jsx
1. MÉTRICAS: visits, time on page, scroll depth, add-to-cart, conversion rate, refund rate

2. A/B TESTING priority: headline > CTA wording > precio anchor > hero > testimonials orden > FAQ

3. UMBRAL: mínimo 1000 visits por variante O significance estadística + 7 días

4. ITERACIóN basada en data:
   - Bounce alto en hero → mejorar headline
   - Scroll bajo → mejorar gancho de secciones
   - ATC alto pero purchase bajo → mejorar checkout
   - Purchase OK pero refunds altos → expectation setting

5. HEATMAPS Y RECORDINGS: Hotjar / Microsoft Clarity (gratis)

6. SURVEY post-purchase + post-no-purchase: ¿qué te convenció? ¿qué te frena?

Objetivo: 10-30% mejora en 90 días con iteración basada en data, no opinión.
```

*Tip pro:* Crea un **Project en Claude** con tu sales page actual + analytics. Cada mes pide "¿qué cambiarías basándote en performance del mes?". Iteración inteligente sin contratar copy expert cada vez.
