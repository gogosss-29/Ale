En este video, exploramos el módulo HTTP en Make, abordando cómo funcionan las aplicaciones y las APIs, y la importancia de comprender su funcionamiento.

Mostramos un escenario real de un cliente donde se utiliza HTTP para gestionar membresías y se detalla cómo desactivar membresías, además de la importancia de los endpoints y los métodos POST y GET.

Instruimos sobre la necesidad de leer la documentación API y realizamos una prueba de funcionamiento.

Finalmente, destacamos la variabilidad entre APIs y la importancia de seguir las instrucciones para utilizar HTTP correctamente.
