En este video, detallamos paso a paso cómo configurar un webhook para automatizar procesos.

Comenzamos explicando qué es un webhook y cómo se inicia un escenario complejo a partir de él.

Mostramos ejemplos prácticos de cómo un chatbot puede enviar información a un webhook para desencadenar una secuencia de acciones.

Luego, demostramos cómo configurar un webhook con Hotmart y Typeform, y mostramos cómo recibir y utilizar la información enviada.

Finalmente, realizamos pruebas en vivo para verificar el funcionamiento del webhook.
