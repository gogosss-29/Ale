# 📊 Analítica y Datos (22 skills)

> Ruta: Claude Code › 📊 Analítica y Datos (22 skills)

**📎 Recursos:**
- Analítica y Datos

---

Sin datos, estás navegando a ciegas. Pero los datos sin insight son solo números en una hoja. La verdadera ventaja competitiva es entender qué dicen tus números y cómo actuar sobre ello.

No necesitas ser data scientist. Necesitas saber qué métricas importan, cómo configurarlas, cómo leerlas, y cómo traducirlas en decisiones que movilizan el negocio. Estos skills te enseñan exactamente eso — desde configurar Google Analytics correctamente hasta diseñar tests A/B que generan insights reales.

Cada skill aquí es una herramienta que usarás una y otra vez. La diferencia entre intuición y decisión informada empieza aquí.

¿Para Quién Es?

- Fundadores que tienen datos pero no saben interpretarlos

- Emprendedores de ecommerce o SaaS que necesitan optimizar por números

- Marketers que quieren pasar de 'siento que funciona' a 'los datos dicen que funciona'

- Consultores que necesitan justificar decisiones con data

Los 22 Skills de Esta Categoría:

1. Analisis Cohorte

Crea marcos de análisis de cohorte para entender retención, ingresos y patrones de comportamiento a lo largo del tiempo. Utiliza cuando midas cómo se desempeñan grupos de usuarios a lo largo de su ciclo de vida.

2. Analisis Embudo Conversion

Mapea y analiza embudos de conversión con identificación de abandono, prioridades de optimización y benchmarking. Utiliza cuando diagnostiques dónde se pierden prospectos en tu proceso de ventas.

3. Analisis Encuesta

Analiza resultados de encuestas con resúmenes estadísticos, tabulaciones cruzadas, identificación de tendencias y recomendaciones de insights accionables. Utiliza cuando interpretes datos de encuestas para decisiones.

4. Analisis Retroalimentacion

Analiza datos de retroalimentación del cliente para identificar temas, patrones de sentimiento y prioridades de mejora accionables para decisiones de producto y servicio.

5. Analisis Sentimiento

Analiza el sentimiento del cliente desde reseñas, redes sociales y tickets de soporte con seguimiento de tendencias, categorización de temas y recomendaciones de alerta. Utiliza para monitoreo de salud de marca.

6. Biblioteca Prompts

Organiza y documenta bibliotecas de prompts reutilizables con categorías, variables y puntuación de calidad. Utiliza cuando construyas una colección estructurada de prompts de IA para tu negocio.

7. Constructor Dashboard Kpi

Configura dashboards de seguimiento de KPI en Notion con métricas, objetivos, indicadores de estado y seguimiento de tendencias para cualquier tipo de negocio. Utiliza cuando un usuario desee rastrear desempeño de negocio, necesite un dashboard visual para métricas clave o desee reemplazar hojas de cálculo dispersas con una vista centralizada de KPI.

8. Dashboard Metricas Saas

Configura dashboards de métricas SaaS rastreando MRR, churn, LTV, CAC, ingresos de expansión y retención de cohorte. Utiliza cuando construyas o mejores analítica de negocio de suscripción.

9. Diseno Dashboard Datos

Planifica diseños de dashboards de datos con selección de métricas, tipos de visualización, frecuencia de actualización y diseño enfocado en el usuario. Utiliza cuando construyas dashboards que impulsen decisiones.

10. Estructura Comisiones Marketplace

Diseña estructuras de comisiones para marketplace con modelos de comisión, niveles premium y análisis competitivo. Utiliza cuando establezca o reestructure precios para un negocio de plataforma.

11. Guia Configuracion Analytics

Planifica la implementación de analítica web con seguimiento de eventos, objetivos, configuración de conversión y configuración de dashboard. Utiliza cuando configures Google Analytics o herramientas similares desde cero.

12. Guia Definicion Metricas

Crea glosarios de métricas definiendo cómo se calcula, rastrea e interpreta cada KPI de negocio con fórmulas, fuentes de datos y propiedad. Utiliza para alineación de equipo en números.

13. Medicion Impacto Social

Diseña marcos de medición de impacto social con indicadores, métodos de recopilación de datos y plantillas de reporteo.

14. Metricas Marketplace

Define y rastrea métricas de salud de marketplace incluyendo liquidez, take rate, GMV y balance de oferta/demanda. Utiliza cuando midas y optimices desempeño de marketplace.

15. Modelo Atribucion

Diseña modelos de atribución de marketing con mapeo de canal, lógica de ponderación, recomendaciones de reporteo y pasos de implementación. Utiliza cuando comprendas qué canales impulsan conversiones.

16. Paquete Junta Directiva Sin Fines

Crea paquetes de reunión de junta directiva con orden del día, resúmenes financieros, actualizaciones de programas e ítems de voto para gobernanza sin fines de lucro.

17. Plan Prueba Ab

Diseña planes de prueba A/B con hipótesis, variantes, cálculos de tamaño de muestra, métricas de éxito y criterios de significancia estadística. Utiliza cuando optimices conversiones o UX.

18. Plan Recopilacion Datos

Planifica estrategias de recopilación de datos con requisitos de seguimiento, cumplimiento normativo de privacidad, recomendaciones de almacenamiento y pasos de implementación. Utiliza cuando estés construyendo tu infraestructura de datos empresariales.

19. Reporte Benchmarking

Crea reportes de benchmarking industriales comparando métricas de negocio contra estándares y mejores desempeños. Utiliza cuando evalúes cómo se compara tu negocio versus competidores.

20. Reporte Impacto

Crea reportes de impacto anuales con visualización de métricas, historias de beneficiarios y secciones de reconocimiento de donantes.

21. Reporte Subvención

Escribe reportes de progreso y finales de subvención con seguimiento de métricas, actualizaciones narrativas y contabilidad financiera.

22. Valor Vida Cliente (LTV)

Calcula el valor de vida del cliente con segmentación, modelos de predicción y recomendaciones de inversión en retención. Utiliza cuando determines cuánto vale un cliente en el tiempo.

¿Por Dónde Empezar?

Te recomiendo estos 3 para arrancar:

→ Analisis Cohorte: Empieza aquí para entender los fundamentos.

→ Analisis Embudo Conversion: Continúa con esto para aplicar lo que aprendiste.

→ Analisis Encuesta: Completa tu comprensión con este skill.

Tip Pro: No configures Google Analytics buscando vanity metrics. Enfócate en métricas que mueven el negocio: cost per lead, customer lifetime value, retention.
