## ¿Qué es un "Skill"?

Un skill es un conjunto estructurado de instrucciones que le dice a Claude exactamente cómo completar una tarea específica.

**Sin skill:** le pides a Claude "escribe un email" → resultado genérico, sin dirección, sin estrategia.

**Con skill:** Claude sigue un proceso batalla-testeado con fases claras, checkpoints de validación y templates listos. Resultado: profesional, alineado con tu estrategia, en minutos.

Cada skill incluye:

- Metadata (nombre, descripción, autor)
- Cuándo Usar (situaciones exactas donde aplica)
- Principio Fundamental (la idea clave)
- Fases de Trabajo (proceso paso a paso)
- Puntos de Control (validaciones antes de continuar)
- Templates (plantillas listas para usar)
- Anti-Patrones (qué NO hacer)
- Recuperación (cómo salir de problemas si algo se tuerce)
- Casos de Uso (archivo adicional con 5-6 ejemplos prácticos)

## Cómo Usar un Skill (Paso a Paso)

1. Ve a la página de la categoría que necesitas (por ejemplo: Ventas y Embudos)
2. Baja a la sección de RECURSOS
3. Descarga el ZIP de esa categoría
4. Descomprime el archivo en tu computadora
5. Dentro encontrarás una carpeta por cada skill, con dos archivos:  
- El archivo .md (el skill en sí)  
- El archivo casos-de-uso.txt (5-6 ejemplos prácticos)
6. Abre Claude ([claude.ai](http://claude.ai)) y adjunta el archivo .md del skill que quieres usar
7. Claude lo lee automáticamente y te guía paso a paso
8. Sigue las fases, responde lo que Claude te pida, y obtén resultados profesionales en 20-45 minutos

## Tips Pro

- Combina varios skills en un mismo proyecto — ejemplo: lead magnet + email sequence + landing page
- Personaliza los skills editando el archivo .md según tu contexto
- Da contexto específico de tu negocio a Claude — cuanto más detalles, mejores resultados
- No saltes los Puntos de Control — existen para validar que vas en la dirección correcta
- Revisa los archivos de casos de uso antes de empezar — te dan ideas reales de aplicación
- Puedes adjuntar más de un skill a la vez en Claude para proyectos complejos
