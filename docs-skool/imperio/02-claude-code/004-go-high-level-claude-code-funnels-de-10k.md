**Lo que vamos a cubrir paso a paso:**

1. Cómo conectar Claude Code a Go High Level vía MCP (Model Context Protocol), que es el estándar oficial para que las IAs ejecuten acciones en herramientas externas.
2. Cómo crear tu Private Integration Token y configurar los más de 130 permisos disponibles a nivel de subcuenta.
3. La estrategia híbrida MCP + API REST. El MCP de Go High Level solo cubre 36 acciones, pero la API tiene acceso a las 130+. Te muestro cómo dejar que Claude Code use API como fallback automático cuando el MCP no alcanza.
