**Lo que vamos a cubrir paso a paso:**

1. Cómo conectar Claude Code a Go High Level vía MCP (Model Context Protocol), que es el estándar oficial para que las IAs ejecuten acciones en herramientas externas.
2. Cómo crear tu Private Integration Token y configurar los más de 130 permisos disponibles a nivel de subcuenta.
3. La estrategia híbrida MCP + API REST. El MCP de Go High Level solo cubre 36 acciones, pero la API tiene acceso a las 130+. Te muestro cómo dejar que Claude Code use API como fallback automático cuando el MCP no alcanza.
4. El detalle que me costó horas de dolores de cabeza y no aparece en la documentación oficial: agregar `"type": "http"` al archivo MCP.json para que la conexión funcione.
5. Cómo controlar TODO tu CRM por voz desde Telegram, estés donde estés. Mandas un audio, Claude Code ejecuta en tu computador, las cosas pasan en Go High Level. Real.
6. Gestión completa de leads, oportunidades, pipelines, etiquetas, notas, correos, calendarios y workflows, todo en lenguaje natural sin tocar la interfaz.
7. BONUS: el AI Studio de Go High Level (en beta) para construir landing pages dentro del mismo ecosistema.
