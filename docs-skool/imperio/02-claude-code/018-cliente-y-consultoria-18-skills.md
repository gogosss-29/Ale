# 🤝 Cliente y Consultoría (18 skills)

> Ruta: Claude Code › 🤝 Cliente y Consultoría (18 skills)

**📎 Recursos:**
- Cliente y Consultoría

---

Si estás consultando o coachingeando, tu producto es la relación con el cliente y los resultados que generas. Esto requiere un sistema — desde cómo cualificas leads hasta cómo estructuras proyectos hasta cómo entregas máximo valor.

Estos skills te enseñan a vender high ticket (cobrar de verdad), a estructurar proyectos para que sean profitables, a manejar clientes difíciles, y a generar recurrencia y referrals. Sin sistema, consultoría es tiempo vendido. Con sistema, es un negocio escalable.

Aquí aprendes a ser un consultor que genera resultados — no solo alguien que "sabe mucho".

## ¿Para Quién Es?

- Consultores que cobran por hora y quieren pasar a project-based
- Coaches que quieren vender higher ticket y menos sessiones
- Agencias que no saben cómo estructurar proyectos profitables
- Especialistas que quieren armar su propia consultoría

## Los 18 Skills de Esta Categoría:

1. **Cambio Alcance Proyecto**  
Escribe documentos de solicitud de cambio de alcance con evaluación de impacto, cronograma revisado y ajustes de costo para proyectos de cliente.
2. **Constructor Encuestas**  
Crea encuestas de feedback de cliente con preguntas estratégicamente ordenadas, escalas de respuesta y marcos de análisis para medir satisfacción, recabar feedback de producto o validar nuevas ideas.
3. **Diseno Programa Grupos**  
Diseña programas de coaching grupal o fitness con estructura de cohort, cronograma, precios y elementos de comunidad.
4. **Evaluacion Diagnostica**  
Construye herramientas de evaluación diagnóstica para engagement de consultoría con puntuación, benchmarking y lógica de recomendación.
5. **Evaluacion Habilidades**  
Construye herramientas de evaluación de competencias con niveles de competencia, rúbricas de evaluación y recomendaciones de desarrollo.
6. **Formulario Intake Cliente**  
Crea formularios de intake de cliente y cuestionarios que recopilan información esencial del proyecto de manera eficiente.
7. **Garantia Servicio**  
Crea garantías de servicio y compromisos de satisfacción con términos específicos, exclusiones y procedimientos de reclamación.
8. **Generador Cuestionarios**  
Genera cuestionarios y evaluaciones con opción múltiple, verdadero/falso y preguntas de respuesta corta con claves de respuesta.
9. **Grupo Mastermind**  
Diseña estructuras de grupos mastermind con selección de miembros, formatos de reunión, protocolos hot seat y sistemas de responsabilidad.
10. **Historia Transformacion Cliente**  
Escribe narrativas de transformación de cliente con marcos antes/después, cronograma y directrices de presentación ética.
11. **Marco Consultoría**  
Construye marcos de engagement de consultoría con preguntas de diagnóstico, plantillas de análisis y estructuras de recomendación.
12. **Onboarding Agencia**  
Crea un sistema completo de onboarding de cliente para agencias y proveedores de servicios, incluyendo secuencia de email de bienvenida, cuestionario de intake, lista de verificación de reunión de kickoff y directrices de comunicación.
13. **Plan Asociacion Industria**  
Planifica la participación en asociaciones de la industria con selección de membresía, estrategia de participación y posicionamiento de liderazgo.
14. **Plantilla Propuesta Consultoría**  
Crea plantillas de propuesta de consultoría reutilizables con secciones personalizables para diferentes tipos de engagement.
15. **Plantilla Reporte Cliente**  
Diseña plantillas de informes de cliente con resúmenes ejecutivos, visualizaciones de datos y recomendaciones de próximos pasos.
16. **Productizacion Servicios**  
Convierte servicios personalizados en ofertas productizadas con alcance fijo, precios y procesos de entrega para ingresos escalables.
17. **Programa Cohort**  
Diseña programas de aprendizaje basados en cohorts con estructura semanal, interacción de pares, sistemas de responsabilidad y criterios de graduación.
18. **Sistema Feedback Cliente**  
Diseña sistemas de feedback de cliente estructurados con check-ins a mitad del proyecto y revisiones post-proyecto para negocios de servicios.

## Cómo Descargar y Usar Estos Skills

1. Baja a la sección de RECURSOS de esta página
2. Descarga el archivo [Cliente-y-Consultoría.zip](http://Cliente-y-Consultoría.zip)
3. Descomprime el ZIP en tu computadora
4. Dentro encontrarás una carpeta por cada skill con:  
- El archivo .md (el skill)  
- El archivo casos-de-uso.txt (ejemplos prácticos)
5. Abre Claude ([claude.ai](http://claude.ai)) y adjunta el .md del skill que quieras usar
6. Claude te guía paso a paso — solo sigue las fases y responde lo que te pida

## ¿Por Dónde Empezar?

Te recomiendo estos 3 para arrancar:

→ **Cambio Alcance Proyecto**: Empieza aquí para entender los fundamentos.

→ **Constructor Encuestas**: Continúa con esto para aplicar lo que aprendiste.

→ **Diseno Programa Grupos**: Completa tu comprensión con este skill.

**Tip Pro:** Tu propuesta no es tu expertise — es el resultado medible que genera para el cliente. Posiciónate por outcomes, no por features.
