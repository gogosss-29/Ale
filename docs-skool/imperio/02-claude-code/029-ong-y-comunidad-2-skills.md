---

Si trabajas en una ONG, causa social o comunidad, el éxito se mide diferente pero no es menos importante. Esta pequeña pero poderosa categoría te proporciona herramientas específicas para recaudación de fondos, gestión de voluntarios, impacto mensurable y comunicación que inspira. Aquí no se trata solo de dinero: se trata de crear movimiento genuino alrededor de una causa que importa.

## Para Quién Es

- Directores ejecutivos de ONGs
- Coordinadores de recaudación de fondos
- Gestores de voluntarios y comunidad
- Organizadores sociales con misión de impacto

## Los 2 Skills de Esta Categoría:

1. **Carta Recaudacion Fondos Ong**  
Escribe cartas de apelación de recaudación de fondos con narrativas, datos de impacto, solicitudes de donación y secuencias de seguimiento.
2. **Reclutamiento Voluntarios**  
Crea campañas de reclutamiento de voluntarios con descripciones de roles, procesos de solicitud y materiales de incorporación.

## Por Donde Empezar?

Te recomiendo estos para arrancar:

→ **Carta Recaudacion Fondos Ong**: Skill fundamental de ong y comunidad

→ **Reclutamiento Voluntarios**: Skill fundamental de ong y comunidad

## Cómo Descargar y Usar Estos Skills

1. Baja a la sección de RECURSOS de esta página
2. Descarga el archivo [ONG-y-Comunidad.zip](http://ONG-y-Comunidad.zip)
3. Descomprime el ZIP en tu computadora
4. Dentro encontrarás una carpeta por cada skill con:  
- El archivo .md (el skill)  
- El archivo casos-de-uso.txt (ejemplos prácticos)
5. Abre Claude ([claude.ai](http://claude.ai)) y adjunta el .md del skill que quieras usar
6. Claude te guía paso a paso — solo sigue las fases y responde lo que te pida

**Tip Pro:** Documenta impacto con datos reales — es lo que motiva tanto a donantes como a voluntarios. Las historias emocionales se olvidan; los números se recuerdan.
