# ⚙️ Operaciones y Sistemas (30 skills)

> Ruta: Claude Code › ⚙️ Operaciones y Sistemas (30 skills)

**📎 Recursos:**
- Operaciones y Sistemas

---

Las operaciones son el corazón silencioso que permite que todo funcione. Mientras otros ven procesos, tú ves oportunidades para automatizar, optimizar y escalar sin caos. Esta categoría cubre desde gestión de inventario hasta automatización de flujos, documentación de procesos y sistemas de calidad. Si tu negocio va a crecer 10x, tus operaciones deben estar diseñadas para ello desde hoy. Aprenderás cómo empresas de rápido crecimiento manejan la complejidad sin perder eficiencia.

## Para Quién Es

- Jefes de operaciones y productividad
- Propietarios de e-commerce y retail
- Gestores de manufactura y supply chain
- Emprendedores que quieren escalar sin contratar 100 personas

## Los 30 Skills de Esta Categoría:

1. **Agenda Reunion**  
Crea una plantilla de agenda de reunión que enfatiza tiempo limitado, puntos clave preparados, y decisiones claras.
2. **Alcance Trabajo**  
Crea un documento de alcance de trabajo claro que define exactamente qué está incluido, excluido y los términos de un proyecto.
3. **Auditoria Automatizacion Procesos**  
Audita procesos operacionales para identificar oportunidades de automatización que ahorren tiempo, reduzan errores y liberen capacidad.
4. **Auditoria Tiempo**  
Audita cómo gastas tu tiempo para identificar dónde va tu tiempo y dónde puedes recuperarlo.
5. **Automatizacion Reportes**  
Automatiza la generación y distribución de reportes para ahorrar tiempo y asegurar reportes consistentes.
6. **Constructor Base Conocimiento**  
Construye una base de conocimiento documentada con procesos estándar, preguntas frecuentes y guías de referencia.
7. **Constructor Rutina Matinal**  
Diseña una rutina matinal personalizada que comienza el día enfocado, productivo y alineado con tus objetivos principales.
8. **Constructor Sop**  
Construye procedimientos operacionales estándar (SOPs) que documenta procesos paso a paso.
9. **Crm Cliente**  
Crea un sistema completo de gestión de relaciones con clientes en Notion con etapas de pipeline, registros de contactos y seguimiento.
10. **Evaluacion Proveedores**  
Evalúa proveedores usando criterios ponderados para asegurar que seleccionas el mejor socio.
11. **Evaluacion Riesgos**  
Realiza evaluaciones de riesgos para identificar amenazas operacionales, financieras y comerciales.
12. **Gestion Energia**  
Diseña un sistema personal de gestión de energía para optimizar el rendimiento.
13. **Gestion Inventario**  
Diseña un sistema de gestión de inventario con niveles de reorden, seguimiento de existencias y auditorías regulares.
14. **Incorporacion Proveedores**  
Crea un proceso de onboarding estandardizado para nuevos proveedores.
15. **Lista Verificacion Aseguramiento Calidad**  
Crea listas de verificación de control de calidad estandarizadas para productos, servicios o procesos.
16. **Mapeador Flujos Trabajo**  
Mapea visualmente workflows para entender cómo se mueve el trabajo a través de los sistemas.
17. **Marco Delegacion**  
Crea un marco de delegación con criterios de decisión, plantillas de transferencia y sistemas de seguimiento.
18. **Matriz Decisiones**  
Crea matrices de decisión ponderadas para opciones empresariales con criterios, puntuación y lógica de recomendación.
19. **Notas Reunion**  
Establece un sistema de notas de reunión estandarizado que captura decisiones, siguientes pasos y propietarios.
20. **Plan Continuidad Negocio**  
Desarrolla planes de continuidad empresarial con evaluación de riesgos, procedimientos de recuperación y protocolos de comunicación.
21. **Plan Gestion Cambios**  
Crea planes de gestión del cambio con análisis de stakeholders, estrategia de comunicación y cronogramas de transición.
22. **Planificacion Anual**  
Facilita la planificación empresarial anual con establecimiento de visión, cascada de objetivos, hitos trimestrales y asignación de recursos.
23. **Plantilla Actualizacion Estado**  
Crea una plantilla estandardizada de actualizaciones de estado que comunica el progreso de forma clara.
24. **Priorizacion Tareas**  
Crea un sistema de priorización de tareas que ayuda a enfocarse en lo que importa realmente.
25. **Procedimiento Escalada**  
Define procedimientos de escalada para problemas de clientes, situaciones de equipo y crisis empresariales.
26. **Rastreador Proyectos**  
Construye un sistema de rastreo de proyectos con hitos, asignaciones de tareas y seguimiento de progreso.
27. **Reporte Semanal**  
Crea un reporte semanal estandarizado que resume la semana, el progreso contra objetivos y próximas prioridades.
28. **Retrospectiva**  
Facilita retrospectivas de equipo para reflexionar sobre lo que funcionó, qué no funcionó, y qué mejorar.
29. **Sistema Procesamiento Lotes**  
Diseña workflows de procesamiento por lotes para tareas repetitivas como facturación, publicación de contenido e informes.
30. **Sop Cumplimiento**  
Crea un SOP de cumplimiento de ordenes que documenta el flujo desde la orden hasta la entrega.

## Cómo Descargar y Usar Estos Skills

1. Baja a la sección de RECURSOS de esta página
2. Descarga el archivo [Operaciones-y-Sistemas.zip](http://Operaciones-y-Sistemas.zip)
3. Descomprime el ZIP en tu computadora
4. Dentro encontrarás una carpeta por cada skill con:  
- El archivo .md (el skill)  
- El archivo casos-de-uso.txt (ejemplos prácticos)
5. Abre Claude ([claude.ai](http://claude.ai)) y adjunta el .md del skill que quieras usar
6. Claude te guía paso a paso — solo sigue las fases y responde lo que te pida

**Tip Pro:** Automatiza lo repetitivo, deja lo humano para lo que requiere criterio. No contrates personas para hacer lo que un flujo puede hacer.
