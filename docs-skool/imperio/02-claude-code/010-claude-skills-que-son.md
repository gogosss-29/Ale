# Claude Skills... ¿qué son?

> Ruta: Claude Code › Claude Skills... ¿qué son?

**🎬 Vídeo (15.9 min):** https://www.youtube.com/watch?v=9JvIRYLwetU&t=242s

---

Cuando Anthropic lanzó los Skills los ignoré por completo. Pensé que era otro nombre fancy para prompts personalizados, y que ya tenía mis sistemas andando con MCPs y custom instructions. No necesitaba una capa más.

Me equivoqué.

El momento que cambió todo fue cuando tuve que planear cinco videos de YouTube antes de irme de viaje. Dos días de trabajo comprimidos en dos o tres horas, gracias a entender cómo usar los Skills correctamente.

En este video muestro las tres Skills que más uso:

**YouTube Creator** — estructura completa de un video desde un audio de 10 minutos. Hook, timestamps, b-roll, descripción, todo. Y se conecta directo a Notion para registrarlo en el Content OS.

**Frontend Design** — rompe con el AI slop visual. Cuando la mezclás con Antigravity o Claude Code, el output deja de verse como "generado por IA" y empieza a verse como un desarrollo real.

**Pedro el Prospectador** — se conecta a Instantly, extrae leads de Apollo, redacta correos personalizados y lanza la campaña. Todo desde lenguaje natural.

También muestro cómo crear tu propia Skill desde cero usando Skill Creator, que es básicamente una meta-skill para construir skills. El ejemplo del video: un contador mensual conectado a Mercury que genera un informe HTML con categorías, insights y balance. Cada mes, mismo proceso, mismo output.

La diferencia clave con los prompts normales: no contaminan el contexto, son reutilizables, y se pueden compartir entre personas de tu equipo o comunidad.
