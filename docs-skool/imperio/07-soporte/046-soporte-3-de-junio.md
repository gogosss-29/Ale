# Soporte - 3 de Junio

En esta sesión altamente práctica y colaborativa, Fran lideró una jornada de resolución de dudas enfocadas en automatizaciones avanzadas con Make, estructuración de flujos para negocios, uso de APIs, scrapers, gestión de stock y automatización de tareas repetitivas. Los participantes plantearon problemas reales en sus proyectos y recibieron orientación estratégica y técnica en tiempo real.

Se abordaron temas como la implementación de Deep Research para análisis de precios inmobiliarios, automatización de mantenimiento en servicios, optimización de procesos de ventas y logística, e integración de sistemas como Google Forms, Sheets, Vapi y software odontológico.

📌 **Lista de preguntas con Timestamps:**

- [01:00] Gerardo – Dificultad para replicar Deep Research en Make. Alternativas con Perplexity y creación de base de datos propia para análisis de mercado inmobiliario.
- [16:18] Ramiro – ¿Cómo cobrar mantenimiento en servicios de automatización? Modelo de ingresos recurrentes y sugerencias para delegar si cambia el enfoque de negocio.
- [21:32] Ramiro – Ideas para automatizar gestión de stock y logística en mayorista de bebidas. Estrategia de doble sistema con Google Sheets y Make para análisis predictivo.
- [30:00] José – Cómo vincular Google Forms con Excel en Make y generar informes automáticos con GPT. Problemas con el módulo "Watch new row" y solución con configuración de triggers.
- [38:44] Gio – Cómo encontrar el contenido de introducción para sacar máximo provecho a Imperio Digital. Se explicó cómo navegar el "Empieza Aquí" en el Classroom de Skool.
- [42:13] Julián – Proyecto de automatización para software odontológico con Make. Uso de iteradores, filtrado de datos y exploración de herramientas como Vapi y Retell para confirmar citas por voz.
