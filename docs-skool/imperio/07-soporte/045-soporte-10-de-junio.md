# Soporte - 10 de Junio

> Ruta: 🛠️ Soporte › Soporte - 10 de Junio

**🎬 Vídeo (74.3 min):** https://www.youtube.com/watch?v=19cHdw85cKo

---

En esta jornada interactiva, Franco lideró una sesión intensiva de resolución de dudas donde se abordaron implementaciones reales de automatización con herramientas como Make, ElevenLabs, Wapi, Google Sheets, Google Docs y Perplexity. Los miembros presentaron desafíos técnicos relacionados con scraping, integración de formularios, conexión de escenarios con webhooks, generación de diplomas automatizados y visualización de datos para dashboards de clientes.

Los participantes no solo recibieron asistencia técnica detallada, sino que también se les orientó sobre cómo estructurar mejor sus flujos, usar APIs especializadas y evitar errores comunes al trabajar con WhatsApp, AirTable y formularios online.

---

### 📌 Lista de preguntas con Timestamps:

- **[****01:00****] Miguel –** Dificultades para integrar ElevenLabs y Make con scrapers para obtener propiedades desde portales inmobiliarios. Se configuró un sistema base que captura parámetros desde una conversación de voz y los utiliza para hacer scraping dinámico en varias webs.
- **[****30:00****] Vilma –** ¿Cómo replicar dashboards conversacionales tipo CRM? Franco recomendó interfaces con Airtable y la integración con CRMs robustos para visualización de datos y automatización de carga desde IA.
- **[****36:00****] Víctor –** Problemas con la activación de WhatsApp API desde Meta. Se recomendó usar Wapi y un número con trayectoria para evitar bloqueos.
- **[****40:55****] Marle –** Cómo validar que personas no repitan encuestas en AirTable y generar una interfaz ordenada para múltiples formularios. Se recomendaron plataformas como Tally y la validación con fórmulas.
- **[****45:45****] Baltazar –** Automatización de creación de Reels Virales. Problemas con webhook entre escenarios en Make. Se solucionó ajustando correctamente la URL del webhook en el segundo escenario y revisando tiempos de ejecución.
- **[****55:25****] Arturo –** Dificultades al usar Perplexity como fuente de información para generar contenido y buscar prospectos. Se aconsejó testear modelos disponibles y utilizar herramientas como Hunter o Apollo para scraping de emails.
- **[****1:04:00****] Raúl –** Cómo conectar Google Sheets con Google Docs para entregar diplomas automatizados. Se le explicó cómo usar `Search Rows` y condicionales para filtrar quién debe recibir el diploma.
- **[****1:09:00****] Jesús –** Problemas con Wapi al responder automáticamente en grupos personales. Se recomendó implementar filtros en Make y seguir las guías específicas para evitar bloqueos.
