📌 **Lista de preguntas con Timestamps (formato por participante):**

- **[****01:31****] Mailin – Webhook no ejecuta automáticamente en Make**  
Tiene un escenario que no se dispara automáticamente desde un agente. Se corrige el trigger y se recomienda revisar el prompt y la memoria del agente.
- **[****21:02****] Eno – Plantillas no visibles con número de prueba de WhatsApp API**  
No puede ver plantillas personalizadas. Se confirma que solo están disponibles con números reales, no con los de testing de Meta.
- **[****25:30****] Carlos – Reutilizar archivos binarios en N8N sin conexiones directas**  
Consulta si se puede usar un binario sin conectar nodos entre sí. Solución parcial: usar nodos `merge`, aunque complica el flujo.
- **[****30:58****] Juani Pi – Conectar WhatsApp + CRM simple para negocio físico**  
Quiere crear un CRM para una ferretería con automatización de mensajes entrantes. Se recomienda usar Wapi + Make + AirTable. También se orienta sobre qué chip usar para WhatsApp Business.
- **[****36:43****] Juani Pi – Cómo estructurar prompts y tool calls para Make Agents**  
Duda sobre cómo estructurar prompts para que el agente funcione bien. Se enfatiza la importancia de una buena descripción de las tools y prompts limpios con Markdown.
- **[****38:51****] Francisco – ¿Por dónde empiezo si quiero hacer múltiples bots?**  
Es nuevo y quiere construir varios bots (Telegram, WhatsApp, imágenes). Se recomienda empezar por el más simple y ganar experiencia desde ahí.
- **[****39:05****] Yodi Isnaga – Automatizar blog diario desde Google Sheets a WordPress**  
Problemas al subir imágenes y ejecutar el flujo. Se recomienda ver video de Henry sobre WordPress y se confirma que sí se puede automatizar con carpetas de Drive.
- **[****43:15****] Igor – Error con Data Store en template de Relevance**  
Al replicar una automatización, tiene errores en tiempos de espera. Se le comparte video completo con plantilla corregida y se sugiere limpiar estructura innecesaria.
- **[****47:44****] Erwin – ¿Gmail automático o usar Mailchimp para evitar spam?**  
Tiene automatizaciones que responden por Gmail, pero teme caer en spam. Se recomienda migrar esas respuestas a flujos dentro de Mailchimp.
- **[****50:32****] Lucho – Presupuestos automáticos con leads de Kommo**  
Consulta si conviene usar GPT para calcular presupuestos o hacerlo en Excel. Recomendación: usar fórmulas en Excel para evitar errores y enviar por correo o WhatsApp vía Wapi.
