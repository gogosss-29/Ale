Durante esta sesión intensiva, se abordaron casos prácticos enfocados en mejorar la integración entre plataformas, automatizar tareas repetitivas y fortalecer el uso de APIs. Se ajustaron configuraciones para calificar CVs por email usando Make, se testeó la eficacia de filtros y rutas condicionales, y se exploraron alternativas con webhooks personalizados. Iván fue asistido en la configuración de una API para análisis de videos de YouTube, mientras que Vilma identificó fallas en la detección de idioma de un agente IA, iniciando una revisión estratégica del onboarding de usuarios. Robert solucionó una conexión con Google Cloud y Lorena corrigió un flujo interrumpido por un webhook mal armado. Fue una jornada con foco técnico, alto valor práctico y múltiples soluciones aplicadas en tiempo real.
