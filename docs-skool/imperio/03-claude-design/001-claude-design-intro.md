—

En este curso te muestro paso a paso:

→ Qué es Claude Design y cómo funciona el workspace completo (con Opus 4.7 corriendo por debajo)

→ Cómo prontear para sacarle el máximo provecho desde el primer mensaje

→ Cómo importar tu branding completo y configurar Design Systems para mantener coherencia visual entre proyectos

→ El flujo completo: idea → prototipo en alta fidelidad → app funcional

→ Cómo editar de manera visual e interactiva (apuntar, dibujar, comentar sobre el diseño)

→ Cómo hacer el handoff a Claude Code y dejar la app corriendo conectada a APIs reales

→ Caso práctico real → vamos a construir una app de meditación desde cero, conectarla a Eleven Labs y OpenRouter, y dejarla deployada
