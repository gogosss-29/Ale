Antes de partir, una cosa que mucha gente confunde y por eso se frustra y se va:

Claude Design NO es un modelo generativo de imágenes. Si le pides una foto de una rana con corona saltando en paracaídas → no te la va a generar. Para eso están Midjourney, DALL·E, Flux, Nano Banana.

Claude Design es un constructor de HTML.

HTML + CSS + JavaScript es el código universal con el que está construido prácticamente todo internet → desde YouTube e Instagram hasta la app de tu banco. Lo que hace Claude Design es escribir ese código por ti, hablando.

Por eso puede hacer landing pages, dashboards, apps móviles, apps de escritorio, réplicas de YouTube, hasta videos animados → todo es HTML por debajo.

Si entiendes esto, todo lo que viene en el curso te va a hacer 10x más sentido.

—

Anthropic acaba de meter en una sola herramienta lo que antes te requería seis suscripciones distintas → Figma, Lovable, Bolt, Stitch, V0 e incluso Canva. Figma cayó 7% el día del lanzamiento. No es casualidad.

Y lo mejor → todo viene incluido en tu suscripción de Claude (Pro o Max). Sin pagar Gamma, ni Figma, ni Canva, ni tocar After Effects.

—

En este curso te muestro paso a paso, con casos de uso 100% reales:

→ Qué es Claude Design, cómo funciona el workspace y por qué corre con Opus 4.7 por debajo

→ Cómo prontear para sacarle el máximo provecho desde el primer mensaje

→ Cómo configurar tu Design System (branding, tipografías, paletas, logos) para mantener coherencia entre proyectos

Los 5 casos prácticos que vamos a construir:

→ CASO 1 → Landing pages desde cero (Hero, CTA, pricing, distribución correcta) en un onehot

→ CASO 2 → Interfaz de app de escritorio multipantalla en modo claro y oscuro (caso real → Ablai, app de dictado para Mac)

→ CASO 3 → App móvil con onboarding completo, integrada a Eleven Labs y OpenRouter, deployada en vivo

→ CASO 4 → Cómo replicar páginas web desde un screenshot (con el disclaimer ético de phishing que tienes que conocer)

→ CASO 5 → Videos animados estilo product launch con CSS, en vertical y horizontal, listos para reels

Y además:

→ Cómo editar de manera visual e interactiva → apuntar, dibujar y comentar directamente sobre el diseño

→ Cómo hacer el handoff a Claude Code para conectar APIs reales y dejar todo desplegado en Vercel o Netlify

→ Los 3 tips que el mismo diseñador de Anthropic (Ryan Mather) recomienda

→ BONUS → Cuándo NO usar Claude Design (esto te ahorra tokens y frustración)

Importante → Claude Design es el frontend (lo que ve el usuario). Claude Code es el backend (lo que sostiene todo por debajo). El verdadero poder está en juntarlos.

Si nunca has tocado Claude Code, dentro de la comunidad tienes el curso completo de +3 horas. Te recomiendo verlo en paralelo a este.

—

Si eres diseñador, agencia, creador de contenido o vendes servicios de IA → esto te multiplica la producción sin sacrificar calidad estética.

Si recién estás partiendo en este mundo → es el momento de aprender el flujo Claude Design + Claude Code antes que el resto.
