### Parte I. Instalación y setup base

El objetivo de esta página es dejar **todo listo para empezar a construir**.  
Sin este setup base, nada de lo que sigue en el curso va a funcionar correctamente.

Aquí no vamos a crear lógica ni pantallas todavía.  
Vamos a preparar el entorno, las cuentas y las conexiones necesarias para trabajar con Antigravity de forma estable y profesional.

### Qué vamos a hacer en esta página

En este módulo vamos a:

1. [Instalar Antigravity ](https://antigravity.google/download)según tu sistema operativo.
2. Crear las cuentas necesarias para el curso.
3. Configurar la estructura base del proyecto.
4. Conectar Antigravity con los servicios clave que usaremos durante todo el curso.

Todo lo hacemos paso a paso, desde cero, usando cuentas nuevas para que puedas replicarlo sin fricción.

### Instalación de Antigravity

Antigravity está disponible para Mac, Windows y Linux.

En este video verás:

- Dónde [descargar Antigravity](https://antigravity.google/download).
- Cómo instalarlo correctamente.
- Cómo completar el onboarding inicial.
- Qué opciones elegir para empezar desde un entorno limpio.

Antigravity es un fork de Visual Studio Code, así que si ya has usado VS Code, la interfaz te resultará familiar.  
  
Si nunca lo has usado, no pasa nada. Lo veremos desde cero.
