Imperiales! En este módulo aprendemos a crear y personalizar **formularios en Airtable**, una forma súper poderosa de ingresar datos sin tocar la base directamente.

🔧 ¿Qué vas a aprender?

- Cómo crear formularios para distintas tablas (como Campañas y Posteos).
- Cómo estructurar campos obligatorios, valores predeterminados y texto de ayuda.
- Cómo usar **filtros de selección** para mostrar solo los datos relevantes (ej: mostrar solo editores en un campo según su rol).
- Aplicar **condiciones de visibilidad**: que ciertos campos solo aparezcan si el tipo de contenido lo requiere.
- Publicar formularios para uso interno o externo, con enlaces compartibles y configuraciones de privacidad.
- Cómo todo se integra automáticamente a tu base con registros limpios y organizados.

💡 Ideal para cuando trabajas con equipos, clientes o colaboradores que no necesitan acceso directo a tu base pero sí pueden aportar datos estructurados.

Si tienes preguntas, mándame un DM o publícalas directamente en Community.  


Seguimos construyendo! 🚀
