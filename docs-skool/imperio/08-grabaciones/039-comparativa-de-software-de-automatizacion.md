# Comparativa de Software de Automatización

> Ruta: 🔴 Grabaciones › Comparativa de Software de Automatización

**🎬 Vídeo (67.2 min):** https://www.youtube.com/watch?v=Joqw43hjw0o

---

La sesión aclara **qué software elegir según cada caso de automatización**: desde la escalabilidad y costos de Make vs N8N, hasta la gestión de datos en Airtable frente a Google Sheets. Además, se exploraron opciones para conectar WhatsApp Business y API con herramientas como **Wapi, Evolution, ManyChat y Chatwoot**, resolviendo dudas comunes sobre integración, costos y escalabilidad.

---

## **Intervenciones**

- **[00:07] Franco – Introducción**  
Contexto de la sesión: análisis de software vigente a septiembre 2025 y comparativa entre distintas herramientas para automatización, bases de datos y WhatsApp.
- **[03:00] Franco – Make vs N8N**  
Explicación de cuándo usar Make (simple y rápido, con pricing por operación) y cuándo usar N8N (más técnico, pero escalable en costos con servidores propios). Ejemplo de analogía: Make como auto automático y N8N como auto manual.
- **[07:41] Víctor – Automatización con imágenes**  
Pregunta sobre generar imágenes y descripciones para Instagram.  
**Respuesta:** N8N suele ser más barato en gran volumen, pero Make es más fácil para manipular imágenes. Se recomienda usar GPT por estabilidad, aunque Gemini y otras opciones son válidas.
- **[09:24] Freddy – Chatbot en Make con WhatsApp**  
Consulta sobre si migrar a N8N.  
**Respuesta:** Si ya funciona en Make y no hay problema de costos, no tiene sentido migrar.
- **[11:18] Jorge – Servidor para N8N**  
Pregunta sobre costos y hosting.  
**Respuesta:** Hostinger funciona bien; lo técnico es más importante que el proveedor.
- **[12:26] Joani – Consejo sobre Hostinger**  
Explica cómo aprovechar promociones para reducir costos y montar varias herramientas junto con N8N.
- **[14:10] Franco – Airtable vs Google Sheets**  
Comparativa práctica: Airtable como base de datos estructurada con interfaces, formularios y automatizaciones; Google Sheets como hoja de cálculo más flexible en fórmulas pero menos robusta para proyectos grandes.
- **[21:46] Jorge – Acceso de clientes en Airtable**  
Consulta sobre cómo compartir datos sin exponer la base.  
**Respuesta:** Se entrega acceso a **interfaces**, nunca a la base de datos directamente.
- **[24:02] Víctor – Integrar asistentes de OpenAI con Airtable**  
Consulta sobre enlazar datos a asistentes.  
**Respuesta:** Mejor hacerlo vía Make o N8N, no desde la plataforma nativa de OpenAI.
- **[32:17] Franco – WhatsApp Business vs API**  
Explicación de inbound (cliente inicia) → WhatsApp Business, vs outbound (empresa inicia, difusiones masivas) → WhatsApp API.
- **[37:00] Franco – Wapi vs Evolution API**  
Comparación: Wapi es simple y rápido de implementar, pero falla más; Evolution es más técnico pero más estable y barato en servidores propios.
- **[43:43] Carlos – Problemas recientes**  
Consulta sobre caídas.  
**Respuesta:** Wapi suele fallar más, Evolution es más estable.
- **[47:02] Freddy – Uso de WhatsApp Cloud API**  
Explica su caso de chatbot con Make.  
**Respuesta:** Es válido y no debería dar problemas; cada enfoque tiene variantes correctas.
- **[53:03] Freddy – Frontend para clientes**  
Consulta sobre darle un panel al cliente.  
**Respuesta:** Se recomienda ManyChat o Chatwoot como frontend para WhatsApp.
- **[55:13] Franco – ManyChat vs Chatwoot**  
ManyChat: fácil, integrado con Meta, ideal para Instagram y WhatsApp API.  
Chatwoot: más técnico, versión gratuita en servidores propios, buena alternativa para equipos grandes.
- **[59:22] Freddy – Migrar de Make a ManyChat**  
Consulta si puede aprovechar lo que ya tiene.  
**Respuesta:** Muchas integraciones hay que rehacer, pero es posible conectar Make o N8N a ManyChat para ampliar capacidades.
- **[1:03:20] Franco – Herramientas No-Code para Frontend**  
Breve repaso de **Bolt, Lovable y Bubble** como opciones para crear apps y frontends sin código.
- **[1:06:05] Consulta – WhatsApp con Go High Level**  
Confirmación de integración mediante plugins de terceros.
- **[1:06:43] Franco – Cierre**  
Conclusión de la sesión: entender **qué software usar según la necesidad** y usar esta grabación como referencia para nuevos miembros.
