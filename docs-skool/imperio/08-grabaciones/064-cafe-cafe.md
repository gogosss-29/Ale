# Café Café

> Ruta: 🔴 Grabaciones › Café Café

**🎬 Vídeo (55.9 min):** https://youtu.be/8u4Am6s9Bfk

---

Hoy Fran nos deleitó con un caso de cliente que requiere desarrollo de automatización, incluyendo el uso de herramientas como Make, OpenAI y un CRM para gestionar suscripciones de café. También demostró cómo utilizar filtros y criterios para buscar correos electrónicos específicos, personalizar y formatear correos electrónicos, y automatizar la extracción de información de nombres completos. Por último, explicó cómo crear una automatización en un sistema CRM para gestionar suscripciones de clientes y destacó la importancia de adaptar y modificar las ideas cuando no funcionan según lo planeado.
