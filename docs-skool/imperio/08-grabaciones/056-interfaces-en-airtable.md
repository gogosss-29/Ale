# Interfaces en Airtable

> Ruta: 🔴 Grabaciones › Interfaces en Airtable

**🎬 Vídeo (56.0 min):** https://www.youtube.com/watch?v=-zuz8YUz3sA&feature=youtu.be

---

En esta edición de **“Automatiza con Fran”**, Franco Ricci nos lleva a fondo en el mundo de las **interfaces en Airtable**, explicando cómo construir soluciones visuales efectivas para clientes y usuarios finales, separando el backend del frontend.

Durante la clase, se abordaron temas clave como:

- **¿Qué es el frontend en automatización?** Fran explicó la importancia de crear interfaces visuales claras para clientes que no deben ver la complejidad interna de las automatizaciones.
- **Ventajas de Airtable como frontend:** Cómo las interfaces permiten mostrar y editar información de forma controlada y atractiva, sin dar acceso directo a las bases de datos sensibles.
- **Casos reales de uso:** Se mostraron dashboards reales implementados con Airtable para firmas de inversión, agencias y equipos de ventas, incluyendo CRM, control de carteras, rankings de vendedores y automatización de pagos de comisiones.
- **Integración con Make y automatizaciones:** Fran mostró cómo Airtable no solo sirve como interfaz, sino también como nexo entre el backend (Make) y el usuario final, incluyendo automatizaciones vía Webhooks.
- **Limitaciones y buenas prácticas:** Se habló sobre los límites del plan gratuito de Airtable, las limitaciones de personalización visual de las interfaces, y cómo sortearlas inteligentemente.
- **Preguntas de la comunidad:** Miembros como Marli, Roma, Javier y Oscar plantearon dudas reales sobre cómo implementar formularios inteligentes, evitar duplicación de registros, conectar Airtable con apps externas y más.
- **Construcción en vivo de una interfaz desde cero:** Fran armó un dashboard completo mostrando la carga de trabajo de distintos miembros del staff (editors, media buyers, encargados), enseñando paso a paso cómo personalizar y filtrar la visualización de datos.

Además, se discutió cómo las interfaces pueden ser una poderosa herramienta de **visualización para la toma de decisiones** basada en datos.
