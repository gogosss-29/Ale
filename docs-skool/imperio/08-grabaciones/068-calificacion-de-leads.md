**JSON Descargable Abajo!**

En esta sesión Fran presentó un proyecto de automatización para el área de ventas de un negocio, utilizando herramientas como Make, Typeforme y OpenAI, con el objetivo de proporcionar una plantilla flexible que los participantes puedan adaptar a sus necesidades. Demostró cómo configurar un sistema de calificación de leads utilizando un asistente de IA, crear una base de datos en Airtable para almacenar información de leads calificados y desarrollar una automatización para gestionar leads y programar reuniones. 

También discutió cómo agregar un retraso en el envío de correos electrónicos para que parezcan más personalizados, y los problemas con los filtros y el formato de los correos generados por GPT.
