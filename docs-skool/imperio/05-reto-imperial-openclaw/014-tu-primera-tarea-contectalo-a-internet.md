# 🆕 Tu primera tarea: contéctalo a Internet

> Ruta: 🦞 Reto Imperial OpenClaw › 🆕 Tu primera tarea: contéctalo a Internet

---

Para que el agente trabaje de forma autónoma necesita poder buscar información en la web. La forma estándar es darle una clave API de **Brave Search**.

**Pasos:**

1. Crea una cuenta gratuita en [brave.com/search/api](http://brave.com/search/api).
2. Genera una API Key (el plan gratuito suele alcanzar para empezar).
3. Pásasela a tu agente y pídele que la configure.
4. Pruébalo: pídele que te traiga la última noticia sobre algo específico de hoy.

## Resultado esperado al cerrar esta lección

- HeartBeats, CronJobs y Skills entendidos a nivel concepto.
- Telegram conectado y funcionando (texto + audio).
- OpenClaw corriendo como servicio persistente.
- Framework SOUL aplicado: el agente sabe quién eres y cómo trabajas.
- Brave Search activado: el agente puede investigar en la web.

Tómate el tiempo que necesites en esta lección. La calidad del setup y del contexto que le des aquí define todo lo que viene después.
