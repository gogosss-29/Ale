# 🛠️ Integración de Tools

> Ruta: De Make a n8n › 🛠️ Integración de Tools

**🎬 Vídeo (13.3 min):** https://www.loom.com/share/9edbd156ad8a4bcc893d41caa9f30a4e

---

En este video vemos cómo conectar herramientas a tus agentes de IA en N8N, desde nodos simples como Google Calendar hasta flujos completos usando *Code Generated Workflow Tool*. 

Aprenderás a configurar tools por servicio, cuándo conviene usar un nodo directo y cuándo armar un workflow separado, cómo pasarle variables al agente y qué detalles cuidar para que accione bien cada herramienta. 

También te mostramos cómo escribir los prompts para que el agente entienda cuándo y cómo llamar cada tool. Esta parte es clave para que tu IA no solo hable, sino también ejecute. 

Una tool hace un "llamado" a algo en específico, a ejectuar una acción (en términos básicos). Clave para llevar tus agentes de IA del chat a la acción real.
