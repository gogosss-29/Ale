# 🔄 Condiciones y Rutas

> Ruta: De Make a n8n › 🔄 Condiciones y Rutas

**🎬 Vídeo (10.3 min):** https://www.loom.com/share/9ae2a843450d489abc5099adbb5ff8c6

---

En este video empezamos a construir un flujo real en N8N usando Airtable como base de datos.

Aprenderás a usar nodos clave como *search records*, *if*, *update* y cómo aplicar lógica condicional para que el flujo se bifurque según los datos. Vemos la diferencia entre *filter*, *if* y *switch*, y cuándo conviene usar cada uno.

Ideal para automatizar decisiones como “si cumple esto, hace A, si no, hace B” y actualizar datos de forma dinámica.
