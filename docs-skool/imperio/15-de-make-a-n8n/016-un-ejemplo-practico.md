# 🚀 Un Ejemplo Práctico

**🎬 Vídeo (4.4 min):** https://www.loom.com/share/cb8beeac51e446c0a2f1a41b264d8430

En este video vemos un ejemplo real de un agente de IA funcionando con múltiples tools conectadas: desde llamadas HTTP simples hasta workflows más complejos como la transcripción de audios.

Exploramos cómo estructurar el *System Prompt* con variables dinámicas, cómo el agente decide qué tool usar según el contexto, y cómo aprovechar la flexibilidad de N8N para adaptar el comportamiento del agente según datos, horarios o tipo de usuario.

Ideal para pasar de la teoría a la acción y ver cómo todo empieza a integrarse.
