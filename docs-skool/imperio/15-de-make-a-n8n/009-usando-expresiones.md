En este video aprendemos a trabajar con expresiones en N8N usando JavaScript como base para mapear variables, acceder a datos y formatear información.

Te mostramos cómo funciona la sintaxis paso a paso, cómo referenciar nodos anteriores con `JSON`, cómo usar `item`, cómo formatear fechas, y qué tener en cuenta para evitar errores comunes.

Fundamental si quieres pasar de arrastrar nodos a controlar con precisión cómo fluyen los datos.
