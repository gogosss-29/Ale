# 🌐 Llamadas HTTP

> Ruta: De Make a n8n › 🌐 Llamadas HTTP

**🎬 Vídeo (4.7 min):** https://www.loom.com/share/2c27bc662cf94c1bb366f6273dd4d916

En este video vemos cómo usar el nodo HTTP en N8N para hacer llamados a APIs externas.

Aprenderás a configurar métodos, headers, autenticación y cuerpo del mensaje. Además, exploramos una función muy útil: *Importar desde CURL*, que te permite armar una llamada desde una API Reference y pegarla directo en N8N sin hacerlo manualmente.

Ideal para integraciones más técnicas o personalizadas, sin complicarte con código.
