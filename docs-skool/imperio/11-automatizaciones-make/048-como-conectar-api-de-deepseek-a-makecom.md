# Cómo Conectar API de Deepseek a Make.com

> Ruta: Automatizaciones Make › Cómo Conectar API de Deepseek a Make.com

**🎬 Vídeo (5.7 min):** https://www.youtube.com/watch?v=b2LsebP2Qao

---

En el video te muestro en los que puedes comenzar a integrar Deepseek R1 en tus automatizaciones en Make.com. 

Super interesante si necesitas un modelo más económico y donde la lógica y resolución de problemas toma mayor protagonismo y es más importante.

1) El primer método es directamente desde la API de [platform.deepseek.com](http://platform.deepseek.com) 

2) El segundo método es usando [openrouter.ai](http://openrouter.ai) , una integració nque te permite trabajar con una amplia gama de modelos, y ver el que se adapte mejor a tus necesidades.

Les dejo este tutorial rapidito para los y las que les interese.
