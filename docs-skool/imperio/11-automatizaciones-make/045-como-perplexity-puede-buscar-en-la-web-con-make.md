## 🎙️ Transcripción

Acá les dejo un video super breve de cómo, de cómo usar perplexity como hacer que Perplexity busque en la web desde Make. Nosotros lo tenemos acá, lo mas importante es el modelo que elijamos, tiene que ser este, Sonar Huge 128K. acá online, este funciona hoy en día, día 6 de enero, para hacer resúmenes de artículos y para entrar en la web. Yo lo configuré de esta forma, acá le cargo el artículo, que es bastante variable, no hay problema con eso, vamos a ver por ejemplo si agarro otro artículo que tenga por acá, ejemplo Copio, vuelvo a Make, le cambio el artículo este, lo corremos y ahí vemos que agarro este artículo, lo que le mandamos Fue justamente eso. A Proplexity vamos a esperar a que cargue. Acá tenemos esto. Un turista en la playa de Unión. Lo que sea. Bien, un resumen bastante tranquilo. Después si quieren modificar la longitud del resumen, quieren modificar la longitud del resumen o el formato, simplemente le modifican el PRO. Pero con este modelo funciona para buscarlo en la web.
