### Cómo Conectar ManyChat con Make para Automatizar tus Procesos

**Bienvenidos a este tutorial donde aprenderemos cómo conectar el API de ManyChat directamente con Make**, dos herramientas esenciales para la automatización de tus flujos de trabajo en redes sociales y marketing.

#### ¿Qué es ManyChat?

ManyChat es una plataforma que te permite **automatizar interacciones** en canales como Instagram. Imagina que subes un reel donde pides a tus seguidores que comenten algo específico y, a cambio, les envías un mensaje privado con más información. Esta estrategia me permitió **recopilar más de 6,000 correos electrónicos** usando un call-to-action en Instagram.

#### ¿Qué es Make?

Make es una herramienta que facilita la integración y automatización de procesos entre diferentes plataformas sin necesidad de tener conocimientos avanzados en programación. En este tutorial, veremos cómo usar Make para conectar ManyChat y, por ejemplo, enviar automáticamente los correos electrónicos que recolectes a plataformas como MailerLite u otras herramientas de email marketing.

### Paso a Paso para Conectar el API de ManyChat con Make:

1. **Generar la API Key en ManyChat** - Primero, asegúrate de tener una cuenta en ManyChat. Si no tienes una, puedes crearla [aquí](https://bencorde.com/manychat).
- Ve a la sección de **Configuración** de tu cuenta y selecciona la opción **API**.
- Dentro de esta sección, genera tu **clave API** y cópiala. La necesitarás para los siguientes pasos.
2. **Crear la Conexión en Make** - Ahora, ingresa a Make. Si aún no tienes cuenta, puedes registrarte [aquí](https://bencorde.com/make).
- Una vez dentro, busca el módulo de **ManyChat** y selecciona la opción **Watch Incoming Data**. Esto es clave para crear un webhook que permitirá recibir datos de ManyChat.
- Nombra la conexión, en este caso podrías llamarla algo como **ManyChat V Corde**, o el nombre de la cuenta de Instagram que vas a asociar.
- Ahora, ingresa el **Access Token** que obtuviste en ManyChat y **guarda** la conexión.
3. **Configuración de Webhooks y Automatizaciones** - Con la conexión lista, ya puedes empezar a usar los **webhooks** y otros módulos de ManyChat en Make. Esto te permitirá, por ejemplo, agregar automáticamente un suscriptor, enviar mensajes automáticos, o exportar contactos a tu lista de MailerLite.
- En mi caso, esta integración ha sido clave para gestionar más de **20,000 contactos** y automatizar diversas interacciones con mi audiencia.

### Conclusión

Conectar el API de ManyChat con Make no solo te permitirá **optimizar tu tiempo**, sino que también te dará la posibilidad de crear automatizaciones mucho más potentes y eficientes para gestionar tu comunidad en Instagram y otras plataformas.
