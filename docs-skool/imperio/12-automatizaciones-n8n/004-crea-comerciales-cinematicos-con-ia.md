Este sistema te permite automatizar la producción completa de comerciales cinematográficos, orquestando desde la dirección creativa hasta el render final. 

Utiliza un flujo de n8n para integrar la generación de imágenes consistentes (Nano Banana), animaciones de video (Veo 3.1), música original (Suno) y voz en off (ElevenLabs), todo por una fracción del costo de una producción real.

Como configurar las conexiones de las APIs (Wavespeed, Airtable, etc.) tiene sus trucos, separé esa parte para que sea más fácil de seguir.
