# 🎬 Banco de escenarios de grabación

Imágenes de referencia de ambientes para generar/ubicar el avatar (paso "Imágenes"
del método). Organizado por carpetas de categoría. Cada imagen queda registrada
acá con su fuente.

## Cómo se usa
Elegís un escenario de acá → lo cargás como **imagen de ambiente** en Flow → el
avatar se ubica en ese entorno (sesión de fotos para el frame de referencia, o
directo en los clips).
